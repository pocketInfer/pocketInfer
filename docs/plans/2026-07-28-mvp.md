# PocketInfer MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a deterministic, memory-bounded config compiler for Kimi K3 and
GLM-5.2.

**Architecture:** A dependency-free Python core selects a model adapter, enumerates
valid discrete configurations, filters them against weight and cache budgets, and
emits the highest-scoring config plus a fidelity manifest. Model semantics remain
isolated in adapters.

**Tech Stack:** Python 3.11+, standard library, pytest, ruff, uv, hatchling.

---

### Task 1: Core contracts and size parsing

**Files:**
- Create: `src/pocketinfer/models.py`
- Create: `src/pocketinfer/sizes.py`
- Test: `tests/test_sizes.py`

Implement immutable budget and policy contracts, parse human-readable byte
budgets, and verify decimal versus binary units.

### Task 2: Generic scaling engine

**Files:**
- Create: `src/pocketinfer/engine.py`
- Create: `src/pocketinfer/adapters/base.py`

### Task 3: Kimi K3 adapter

**Files:**

Preserve KDA/MLA width, LatentMoE, SiTU, top-k, MXFP4, and vision fields. Rebuild
KDA/full-attention layer lists and prefer an AttnRes-crossing topology.
